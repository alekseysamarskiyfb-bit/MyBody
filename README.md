# Тренировки

Приложение для домашних тренировок: Пн, Чт, Сб, цикл из трёх недель (лёгкая, средняя, тяжёлая).
Один статический файл `index.html`, без сборки и зависимостей. Данные хранятся на телефоне (localStorage).

## Как выложить

1. Создай репозиторий на GitHub и загрузи в него все файлы из этой папки (Add file → Upload files).
2. На vercel.com нажми Add New → Project, выбери этот репозиторий.
3. Framework Preset: Other. Build Command и Output Directory оставь пустыми. Нажми Deploy.
4. Открой адрес в Safari на iPhone, нажми «Поделиться» → «На экран Домой».

Данные привязаны к адресу сайта. Если сменишь домен, план придётся ввести заново.
